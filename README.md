# Hammer Throw Conversion Calculator

Public Streamlit app for converting hammer throw distances across implements.

**Rule:** every +1.0 kg = −6.0 meters  
Distances are clamped at 0.

### Features
- Men & Women weight ranges
- Meters ↔ Feet conversion
- Highlighted base implement
- Distance vs. weight curve

🔗 **Live app:** https://hammer-converter.streamlit.app
